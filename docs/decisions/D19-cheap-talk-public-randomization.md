# D19: mixed static cheap talk induces base correlation

- **Status:** adopted and promoted
- **Date:** 2026-07-30
- **Experiment IDs:** EXP-047

## Decision / question

Whether public randomization generated by mixed play of observable cheap talk
belongs to the static Core bridge, requires a staged Protocol model, or should
introduce a communication-specific mixed equilibrium concept.

## Competing designs

1. Push the independent law of mixed cheap-talk strategies through the
   realized action profile and prove the correlation result by exact finite-law
   equalities.
2. Represent the messages and actions as separate Protocol stages, then
   transfer an execution equilibrium to the base form.
3. Add a cheap-talk-specific mixed Nash or correlated-equilibrium predicate.

Design 1 is adopted for the induced action law and the theorem that mixed Nash
cheap talk induces a base correlated equilibrium. Design 2 remains reserved
for theorems that observe communication histories or timed randomization.
Design 3 is rejected by the single-equilibrium architecture.

## Representative hostile slice

EXP-047 starts with an arbitrary mixed profile of message-plus-contingent-plan
strategies. A base recommendation-dependent deviation is lifted by retaining
the chosen message and applying the response to every contingent action. The
slice proves:

1. mapping one coordinate of an independent profile law is the independent
   law with that marginal mapped;
2. realized action profiles commute with the lifted deviation;
3. the induced base action-profile laws commute with the same deviation; and
4. ordinary mixed `IsNash` of the cheap-talk form implies ordinary
   `IsCorrelatedEq` of the base form.

The final theorem quantifies over an arbitrary weak preference. This is a
stronger ownership test than an expected-utility-only proof.

## Kill condition

Reject static ownership if the induced action law does not commute with an
arbitrary recommendation-dependent deviation, if the proof needs an
intermediate communication state, if a second evaluator or equilibrium
predicate is required, or if direct `Function.update`, dependent transport,
stored finiteness, or a Core-to-Protocol/Analysis dependency appears.

No kill condition fired.

## Result

Adopt a separate static Core bridge over `GameForm.CheapTalkExtension` and
`GameForm.mixed`. It owns the induced base action-profile law, the lifted
recommendation deviation, exact play/deviation commutation laws, and the
mixed-Nash-to-correlated-equilibrium theorem.

Do not make conditional public-message disintegration part of this decision.
That representation theorem needs its own consumers and measurements. It may
be added later without changing the equilibrium result proved here.

## Consequences for public API

The bridge must stay Protocol- and Analysis-blind, reuse the canonical finite
law and equilibrium predicates, and live separately from the minimal
one-stage cheap-talk construction. Promotion adds positive reachability
for the induced-law and correlation theorems plus negative reachability for
Protocol execution and analytic existence.

## Promotion evidence

`GameTheory/Core/CheapTalkRandomization.lean` contains the static bridge and is
imported by the public Core root after the minimal cheap-talk construction.
The focused target builds in 1,720 jobs and the full project in 3,363 jobs.
Phase 2 preserves every source and import budget, reaches both intended public
symbols, and rejects all four Protocol/Analysis boundary symbols. The
coordinate-map lemma and both CE/CCE results depend only on `propext`,
`Classical.choice`, and `Quot.sound`.
