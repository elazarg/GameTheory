## Representative proof and disproof

The positive Farkas slice works and forces the pure backend rather than relying
on a closed-goal shortcut:

```lean
theorem farkas_certificate (a b : Rat)
    (h₁ : 2 * a + b ≤ 5) (h₂ : a - b ≤ 1) :
    3 * a ≤ 6 := by
  lp (backend := pure)
```

The actual EXP-007 endpoint does not. Before game-specific simplification the
tactic treats opaque update/payoff terms as unconstrained variables and reports
an unbounded objective. After the same four-profile expansion and structural
simplification, it rejects the generated comparison instead of closing it. A
separately written closed rational comparison does close, but that replaces
only the last `norm_num`; it removes neither `pennyProfiles` nor `sum_pennies`.

The smallest generic-game obstruction is also decisive:

```lean
example (u : Rat) :
    ∃ p : Rat, 0 ≤ p ∧ p ≤ 1 ∧ p * u = 0 := by
  lp (backend := pure)
```

The result is:

```text
lp: nonlinear multiplication; one side of `*` must be a
reducibly-closed scalar
```

An arbitrary payoff parameter times an existential probability is exactly the
shape needed by a theorem quantified over finite games. Concrete rational
instances are LPs; a generic CE-existence or minimax theorem is not obtained
from this tactic without an additional formal bridge or duality theorem.
