# Wild ideas index

This directory contains **survey portfolios**, not lifecycle-owned idea groups.
Each survey deliberately compares several unrelated mechanisms, so assigning a
single lifecycle card would conceal rather than clarify their status. A claim
becomes active only after it is extracted into a coherent file beside
[`../INDEX.md`](../INDEX.md), with the card and four ledgers required by
[`../README.md`](../README.md).

Do not record task status in these surveys. Update the owning group when a
promoted claim changes, and create a new group for any newly actionable
descendant.

Each cross-field program has its own file.  These documents distinguish exact
mathematical correspondences from analogies and record the experiments that
currently support or falsify each direction.

Current calibration: fixed rational bounded-discrepancy realization is no
longer the main unknown; the live signal-processing question is causal
realization under every unilateral conditional law.  Exact finite predictive
quotients and generic semialgebraic barrier completeness have both proved too
rigid as general routes, so approximate predictive compression is promoted.
On the analytic side, moving multichain kernels select values through a
Puiseux hierarchy beyond ordinary gain and bias. Exact full-germ block
elimination, affine rebasing, and rectangular affine-data quotient confluence
are now Lean infrastructure through `e0d7462`. The proposed route has moved to
controlled closure under policy choice and useful compression. On the product
side, Q108's selected-packet counterexamples are formalized but remain abstract
packet geometry, not game-shaped or root counterexamples.

The present cross-track order is:

1. **Game-shaped selected-packet selection or embedding** — determine whether
   phase-lifted game balance forces some common product packet, or realize the
   abstract proper-subset obstruction in an actual strategic correspondence;
2. **controlled Schur closure under policy choice** — characterize when exact
   elimination returns one finite controlled system whose legal policies and
   owner-labelled deviations correspond to the original choices;
3. **adversarial causal rounding** — upgrade the landed offline rational
   bounded-discrepancy equivalence to one public causal rule preserving the
   required conditional laws against deviations;
4. **approximate predictive compression** — replace impossible exact finite
   quotients by accuracy-dependent public predictors with uniformly sublinear
   strategic error under every unilateral law.

Thermodynamic or fractal language remains parked unless branch-image
separation or pressure acquires a direct strategic consumer. Cryptographic
randomness, owner-Hodge/Puiseux closure, and global adversarial causal rounding
remain open and are not promoted by the Q118/Q121 developments.

Owner-valued Hodge decomposition remains the most promising obstruction
language across these routes. Generic semialgebraic barrier completeness,
exact predictive quotients, information-only financing of linear punishment
debt, and thermal selection are demoted: each is either false in general or a
special-case heuristic rather than a leading construction.

The Q125--Q131 quitting-debt split promotes one previously secondary idea.
**Retargeting as terminal-set design** is now concrete: exact zero-boundary
optimization can retain positive debt even when a different stationary
terminal equilibrium exists, while the certified relative-boundary splice and
its depth-free mismatch bound are proved. The open part is no longer the
splice but selection of the sustainable replacement target. Q130's geometric
rare-hazard front also gives the multiscale/renormalization language a precise
test object: any scale decomposition must retain the terminal boundary packet
that escapes every fixed rooted window. Q127's linear raw-mass theorem says
that the original owner's terminal packet cannot disappear in total scale,
even though fixed-time normalized marks can. Conversely, Q129 demotes any
owner-Hodge proposal that transfers a local atomwise regret directly into a
new player's dynamic debt; that implication is now false by exact theorem.
