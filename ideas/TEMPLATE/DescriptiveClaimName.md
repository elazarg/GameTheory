# Exact scientific claim

| Field | Value |
| --- | --- |
| Status and maturity | `OPEN/I`, `PROVED/M`, `LANDED/L`, etc. |
| Provenance | Source report/question/commit or external citation |
| Attribution / novelty | Required caveat or source-aligned attribution |
| Formalization | Exact target file/declarations, or `none` |
| Consumer / resolution | Named project consumer, or `INDEPENDENT` plus reactivation condition |

## Exact claim or conjecture

State the mathematical object, quantifiers, hypotheses, and conclusion.

## Intuition and proof status

Give the proof, proof sketch, checked experiment, or exact missing step.

## Falsifiers and wrong inferences

Record the smallest decisive test and the nearest stronger claims not proved.
