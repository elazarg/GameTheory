# Analytic leaves need a gate or a consumed alternative

| Status | Scope | Formalization | Next discriminant |
| --- | --- | --- | --- |
| `MIXED`, maturity `M+L/I` | selected target plus an actual analytic Bellman/value leaf | analytic hierarchy and several gates/no-go examples in production; universal router absent | one actual leaf, one exact gate failure, and a proved closure or obstruction consumer |

An analytic or Puiseux leaf supplies asymptotic algebra. It does not by itself
supply strategic ownership, zero holonomy, a credible response, or a uniform
target. The sound target is a gate-or-alternative theorem:

```text
source-aligned analytic leaf at a declared target
    -> named route gate holds
    OR direct finite closure
    OR adaptive semantic closure
    OR a typed obstruction with a proved downstream consumer.
```

The inference “analytic leaf implies the named invariant” is false: the landed
mixed-owner/holonomy examples exhibit analytic germs that fail the proposed
zero-holonomy gate. A failed gate with no closure or consumed obstruction is an
open branch, not progress toward existence.

The acceptance contract is deliberately concrete. Input data must identify the
game, target, leaf, support/domain, and strategic interpretation. Output must
either instantiate a production credibility/compiler interface or return an
obstruction already known to force a different constructive branch. Merely
classifying jets, endpoints, or curve components is insufficient.

This route does not select the root target and is not known complete. Sorin's
endpoint separation, Big Match memory, and the mixed-owner holonomy
counterexample are mandatory regressions.
