# Contracting periodic certificates compile to uniform-equilibrium payoffs

| Lifecycle | Verdict | Priority | Formalization |
| --- | --- | --- | --- |
| `MINED` | `PROVED` | `P1` reusable compiler | production Lean |

Let a finite quitting game be supplied with a nonempty finite cycle of mixed
quit roots and phase values. Assume:

1. each phase value is exactly the one-step successor payoff generated by the
   current root and the next phase value;
2. each current root is an exact Nash root against that next phase value; and
3. for every player, the product around the cycle of the opponents' Continue
   probabilities is strictly below one.

Then the periodically repeated behavior profile is an exact terminal Nash
profile against arbitrary behavioral deviations. Its phase-selected terminal
value is consequently a uniform-equilibrium payoff, and the same periodic
profile witnesses every positive accuracy.

This is a **compiler**, not a producer: it validates supplied phase roots and
values but does not show that every quitting game admits such a cycle. The
contraction premise is playerwise and is what removes the Never boundary from
the Bellman comparison.

Production declarations are
`isZeroAsymptoticNash_quittingCyclicBehaviorProfile_of_certificate` and
`isUniformEquilibriumPayoff_quittingCyclicTerminalValue_of_certificate` in
`GameTheory/Concepts/Stochastic/QuittingPeriodicCompiler.lean`.
